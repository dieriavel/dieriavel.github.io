Política de privacidad

Última actualización: 21 de septiembre de 2026

Territorio Cerrado analitica es una herramienta interna del canal de YouTube Territorio Cerrado. Solo la usa el propietario del canal para leer las estadísticas de su propio canal.

Qué datos se usan

Con permisos de solo lectura (YouTube Data API y YouTube Analytics API) se leen métricas agregadas del propio canal: visualizaciones, tiempo de reproducción, retención y suscriptores. La herramienta no puede subir, editar ni borrar contenido.

Qué no se hace

No se recopilan datos de espectadores individuales, no se venden ni se comparten datos con terceros y no se usan para publicidad.

Dónde se guardan

Las métricas se guardan en equipos privados del propietario del canal. El acceso puede revocarse en cualquier momento desde la configuración de la cuenta de Google.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Contacto

A través del canal: youtube.com/@territoriocerrado.
